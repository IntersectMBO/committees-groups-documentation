# Budget Reconciliation

In September 2026, the OSC agreed to reframe the Budgets for Project Support Services and Accelerator Program, to cover unplanned overspend across other programs.&#x20;

* **Approval of Accelerator Program for Reimbursment:** Approved using the Accelerator Program budget to reimburse expenses for incident management and travel/events (6 votes Yes, 1 vote Abstain).
* **Approval of Project Support Services Funding:** Approved using Project Support Services to cover the Intersect OSO X premium account, the Crypto EQ Vantage report, and bug bounty reimbursements/outstanding rewards (6 votes Yes, 1 vote Abstain).
* Source: [Meeting Minutes September 3, 2026](../../../osc-meeting-minutes/open-source-committee-meeting-minutes/2026-meeting-minutes/09-03-2026-meeting-minutes.md).&#x20;



In collaboration with the Finance Team (Intersect Administration), a series of audits were conducted to ensure accurate 'repayment' of overspend for each affected program. The spreadsheet linked below details each deposit received by the OSC Wallet and the corresponding outgoing transactions. A near exact breakdown (including Tx and other fees) demonstrates the overages against certain programs. The Accelerator and Project Support Services budgets will be reviewed in a similar fashion, noting the data present in this sheet. Remaining funds \~150k ADA will be attributed to previously approved Bug Bounties (not payable due to original overspend) and the furnishing of a Vantage Report by CryptoEQ.&#x20;
